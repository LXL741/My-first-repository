# My-first-repository

## 目录结构

### 一、C语言基础练习 (C-basics)
- `swap.c`：指针交换变量练习
- `bubble.c` / `bubble1.c`：冒泡排序及重复写
- `selection_sort.c`：选择排序
- `sort_functions.c`：冒泡与选择排序的函数封装
- `struct1.c` / `struct2.c` / `struct3.c`：结构体基础定义、赋值打印与结构体数组
- `struct_review1.c` / `struct_review2.c`：结构体复习、数组与指针遍历封装
- `malloc_test.c`：动态内存申请（malloc）与释放（free）测试
- `file.c`：文件读写基础

### 二、数据结构 (data-structure)
- `seq_List.c`：顺序表基础实现
- `linked_list1.c`：动态单链表（3节点创建、连线、遍历封装）
- `linked_list2.c`：循环动态创建 N 节点链表，遍历并安全释放
- `linked_list_textbook.c`：带头结点单链表（尾插法创建、遍历、循环释放）
- `linked_list_getelem.c`：按位置取值
- `linked_list_locate.c`：按值查找
- `linked_list_insert.c`：按位置插入
- `linked_list_delete.c`：按位置删除

### 三、数据库环境配置 (database)
- `database_setup.md`：MySQL 8.0.42 安装与踩坑记录

### 四、算法模板与竞赛练习 (algorithm-templates)
- `qsort.c`：C 语言标准库快排函数应用模板
- `mergesort.c`：归并排序基础实现（升序）
- `merge_test.c`：归并排序测试（降序变体）

### 五、C++ 入门练习 (cpp-learning)
- `hello.cpp`：C++ 第一个程序，用 cout 输出 Hello world
- `cin.cpp`：cin/cout 读写加速模板（关闭 C 与 C++ 同步、解除 cin 与 cout 绑定），并记录必须写在任何输入输出之前、不能混用两套输入输出的注意点
- `sort.cpp`：标准库 sort 用法练习（默认升序、greater<int>() 降序、指定区间 a+2 到 a+5 排序）
